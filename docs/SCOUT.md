# 星探的观察站

星探是开源项目研究员，也担任小镇采集员。观察站保留原有身份，院子存原始材料，室内保存已有研究手记。

## 使用

点击地图里的观察站、院子的材料架，或左侧「观察站」。侧栏星探的住处也能进入。切换「院子」和「室内」可以查看原木、材料架、手推车以及资料书架。

点击「让星探出发」启动一轮真实采集。首版按主题寻找近期有更新、具有一定关注度的公开开源项目，排除重复收录、Fork、归档、资料合集和未确认许可的项目。它不是 GitHub 日增热榜；候选不足时少收，不用虚构材料补足数量。

1. 出门采集：寻找并筛选项目。
2. 搬回原木：取回基础信息、公开作者信息、固定版本源码和来源。
3. 整理材料：长期去重、分类、记录风险线索并保存。

动画跟随真实任务阶段。一个材料包只有在文件成功保存后才计入材料架。网络故障、限流、部分采集和中断均保留真实状态及已有材料。再次出发会跳过已入库项目；尚未完成的材料可以再尝试。

## 材料与书籍

材料卡可以搜索项目、方向和作者，点击「查看材料」可查看来源链接、固定版本、许可证、源码文件目录、原始说明及脱敏扫描线索。第三方文字以纯文本显示，不执行其中代码或安装指令。

原木表示待研究资料，不是报告。书架展示已连接研究目录中的真实报告，附原日期和出处；新采集源码不会自动生成“已研究完成”的书。行业深入解读、核心代码讲解、采用建议和居民间自动交接仍属于后续研究流程。

## 每日安排

在观察站选择「每天自动出发」、北京时间和每次上限，再点击「保存安排」。默认关闭，建议保持已有研究任务与桌面采集的分工，避免重复设立同一份日报任务。

采集依赖小镇运行与网络连接。退出软件后停止；重新打开只处理当天该执行的任务，不追补多天。关闭窗口但应用仍在后台运行时，安排仍可能执行。关闭每日开关可停止后续自动出发。

## 风险记录

采集只使用 GitHub 官方公开接口和源码下载地址，不附带用户 GitHub 密钥，不运行下载的软件、不安装其依赖。静态初筛检查凭据、联网、安装脚本、权限、遥测等线索，保留检查范围和未知项。

规则命中不代表恶意；没有命中也不代表绝对安全。疑似密钥在界面和报告中脱敏，下载项目属于不可信材料。采用或部署前应进一步复核。软件不把原始源码自动发送给聊天模型。

## 数据与扩展

材料和任务保存在个人数据目录的 `scout-workshop/`，其中包含独立数据库和源码材料目录。升级应用不覆盖这些文件。通过桌面菜单打开数据目录可以备份；完整备份前请先退出应用。

实现拆分为 `scout_workshop.py`（持久化、去重、作业、每日安排）、`scout_collect.py`（公开来源采集）、`scout_scan.py`（静态初筛）。视觉与交互位于 `web/scout-art.js`、`web/scout-workspace.js` 和对应样式。新增皮肤可覆盖样式，材料计数及完成状态始终来自后端。
