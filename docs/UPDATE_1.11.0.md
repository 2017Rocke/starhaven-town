# 星栖小镇 1.11.0 · 双署巡逻与安全档案

更新日期：2026-11-12

巡检警官与网安稽查官入住小镇，分别拥有警察署和稽查署。文件巡检、网络核查、只读执法档案与巡逻画面形成完整流程。

## 两位新伙伴与独立建筑

- 巡检警官：蓝灰制服与警徽，负责检查受管理的文件、技能和材料；警察署配有检查台与证物档案柜。
- 网安稽查官：深青制服与终端，检查文件中的密钥与外发线索，并核查已接入的小镇对外请求；稽查署配有通信天线、监控台、审计账册与独立车库。
- 新增像素警车，巡逻随真实文件巡检开始，任务结束后返署。重开按保存的任务状态恢复画面；未结束的检查标记为中断，不会自动续扫。支持减少动态效果。
- 两位居民分别占用空闲地块，保留旧居民和房屋位置；空间不足时提供说明。

## 检查结果保存在两署

检查结果由程序生成，居民无法通过聊天、材料文字或接口参数写入“已通过”。记录绑定文件内容指纹和规则版本；内容改变或规则更新后提示重新检查，原记录保留。历史记录附有关联摘要，损坏时显示异常并停止放行受监测的请求。

默认每日文件巡检安排为警察署 09:30、稽查署 10:00，均为北京时间；也可手动检查或独立修改安排。应用关闭后暂停，重新打开只执行当天已到时间且尚未启动过的安排。手动启动计入当天，失败或中断后需手动重试。档案与日报说明实际覆盖、跳过原因、疑点及局限。

## 真实请求核查

接入 GitHub 采集和自选模型 API 的发送入口。明显密钥外传、未获准的目的地、不可用的检查记录等情况会暂停请求；保留原有的目标限制与禁止重定向机制。正常请求生成脱敏审计记录。

本机 Codex 和其他外部程序的实际网络行为不在覆盖范围，界面会明确说明。文件检查属于有限静态筛查，不是安全认证；当前不会自动删除或隔离文件。详细范围见 [两署使用与安全边界](SECURITY_OFFICES.md)。

## 同时包含 1.10.0 美术升级

居民住宅、指挥所和观察站已统一门窗比例、木石材质与像素光影；道路、门牌、居民站位更协调。夜景使用独立窗灯，修复了 Mac 原生窗口的夜色滤镜兼容问题。参见 [1.10.0 美术更新](UPDATE_1.10.0.md)。

## 安装与兼容性

Mac 与 Windows 共用同一套居民和场景资源。提供 Apple 芯片、Intel Mac 的 DMG，以及 Windows x64 安装器和便携包。个人聊天、模型配置和采集内容不进入发布包。

Windows 仍以 10.0.17763.379 为兼容目标；现代 Windows 构建测试不能替代该旧系统的完整实机验收。Mac 公开构建采用本地签名，未完成 Apple 公证。安装与系统依赖说明见 [发布文档](RELEASING.md) 和 [Windows 说明](WINDOWS.md)。
