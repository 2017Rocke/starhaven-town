# 星栖小镇 2.2.0 · 初始居民新增梵高与达芬奇

更新日期：2026-11-16。版本标签：`v2.2.0`。下载与构建结果见 [GitHub Release](https://github.com/2017Rocke/starhaven-town/releases/tag/v2.2.0)。

本版把两位在 2.1.0 之后由所有者手动添加的居民纳入公开的初始配置，让全新安装也自带美术与动效岗位，成长署的对应题型可以直接跑起来。

## 初始居民增至十三位

`defaults/residents.json` 新增：

| 居民 | 职责 | 地块 | 形象 |
| --- | --- | --- | --- |
| 梵高 | 像素美术与场景设计 · 建筑外观、绿地与风景 | slot 6（1197, 90） | `artist` |
| 达芬奇 | 动效与工具效果设计 · 关键帧、循环与性能预算 | slot 7（1563, 90） | `maker` |

两人相邻，位于北排中段。全新数据目录现在是十三位初始居民：领航、星探（村心建筑）、吉吉、东日、科德、爬山佬、巡检警官、网安稽查官、杨辉、阿力哥、梵高、达芬奇，以及迁移补入的成长官。小镇最大容量仍为三十三位。

两人的职责写法刻意带上了可检验的数字（`320×280` 地块、四边留 4 像素、相邻帧位移不超过 2 像素、帧数与总时长预算），这样成长署生成的练习会落到可验证的规格上，而不是泛泛的「注意对齐」。

## 与成长署题型的对应

| 岗位关键词 | 岗位族 | 独立检查 |
| --- | --- | --- |
| 美术、视觉、景观、绿地、风景、配色、像素 | `canvas` | 画布边界：`rect` 能否放进 `canvas` 且四边各留 `margin` |
| 动画、动效、特效、关键帧、动作、帧 | `motion` | 动效预算：帧数不超 `max_frames`，且 `frames×frame_ms` 不超 `budget_ms` |

这两种题型是 2.1.0 引入的；本版只是让全新安装也能直接拥有对应的居民。

## 已有存档不受影响

- 初始居民只在**全新数据目录**写入。已有小镇的居民、聊天、记忆、成果与训练记录一律保留，不会因为默认配置变化被覆盖，也不会重复添加。
- 手动添加过同名人物的存档保持原样；本版**没有**为这两位写迁移，避免和已存在的同名居民冲突。
- 升级前仍建议退出应用并复制整个数据目录。

## 支持范围与升级

- 严格预算与自动训练仍只对已验证档案开放：OpenAI `gpt-4o` 系列（`openai-text-bpe-v1`）与 DeepSeek `deepseek-flash`、`deepseek-v4-pro`（`deepseek-reasoning-v1`）。其他兼容端点保留普通聊天。
- 其余功能与 2.1.0 相同：跨机器状态快照、成果目录进对话、训练卡片显示任务要求、预算拒绝按原因报错。
- Windows 构建在 `windows-2022` 上验证，不等于 Windows 10 `17763.379` 实机验收；Mac 产物默认 ad-hoc 签名，未完成 Apple Developer ID 公证。
