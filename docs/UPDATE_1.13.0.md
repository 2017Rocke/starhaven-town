# 星栖小镇 1.13.0 · 村心环岛与环村巡逻

更新日期：2026-11-13。版本标签：`v1.13.0`。下载与构建结果见 [GitHub Release](https://github.com/2017Rocke/starhaven-town/releases/tag/v1.13.0)。

## 小镇的变化

北侧住宅与村心之间改为贯通的双向马路，与其余街道统一为 64 像素宽，连接房前入口、森林步道和东西环路。路面使用统一的灰色和稀疏颗粒，补上车道线、步道、路缘与少量长椅、低矮路灯和绿植；路口和入口处不再被路缘或标线横挡。

为容纳同样规格的马路与两侧各 18 像素路肩，最北排的五块地和森林各向北调整 60 像素，居民保留原地块编号、房屋造型和个人资料。其余普通住宅位置不变；指挥所与观察站的显示位置向北对齐邻侧住宅行。地图北缘随森林延伸，南缘保持原位。警车继续沿外围路网巡逻。

## 村心马路与小波环岛

指挥所与观察站门前改为 64 像素灰色马路，与住宅街道使用相同材质、车道标线和步道。东西两端与外街对齐，北入口拓宽为同规格连接；两座建筑仍由对齐门轴的短径接入步道。

“小波抱星星”雕像位于中央绿岛，周围用阶梯像素勾出环形道路，环带按 64 像素规格设计。主路与北向道路保持笔直，环岛与雕像一起移到两条轴线的交点，外街和木桥直接对齐。指挥所与观察站的绘制位置向北对齐邻侧住宅行，地基与东日、钓鱼佬对应房型保持同高；保存的角色资料不变。环岛避开房屋实体，雕像保留红色身体、圆环天线和金星。木桥继续使用木色桥面、木板纹理与栏杆，桥面净宽与主路对齐，栏杆置于通道外。

材料架移至观察站南侧院子，卸货点同步南移 80 像素，避免占用马路。星探经院落短径进入环岛东侧，再绕开雕像和观察站去森林；环岛内不再叠画石板运输小路。花园、长椅、路灯和树木也留出道路与材料架空间。领航前庭安排计划板与会议桌，观察站前庭安排望远镜与研究桌，中央门路保持畅通。材料区的小车收进独立车位，满载时也不与架体或斧头相交。已有材料与采集任务保留，警车本轮仍使用外围巡逻路网。

## 巡逻变化

警车沿连通路网巡逻，通过两侧环路换街，各条马路都按方向分道。车头有前、后、左、右四种朝向，北排入口也能正常驶入马路。任务结束后从当前实际位置沿路返回，不再斜穿草地或广场。

工作进度和画面行程仍然分开：检查结束就保存真实结果，返署动画随后完成；失败或中断同样返回。重新打开可恢复同一行程，状态失联时冻结，减少动态效果设置继续有效。车辆经过房屋不表示该屋自动通过检查。

## 修复与维护

- 北侧采用完整街道规格，消除密集砖纹造成的墙面观感；同步调整房屋间距、森林边缘和导航。
- 修复北侧两户门口缺少真实道路，以及最东侧巡逻可能越出地图的问题。
- 外围道路绘制和巡逻导航使用同一份道路图，包含住户和森林／村心入口；村心马路与环岛单独绘制，星探行走按实际铺面衔接。
- 增加道路连通、实际铺面、入口、车辆边界、绕行和返程检查。
- Mac、Windows 和源码导出均包含新增模块与像素素材。

## 统一发布流程

项目新增 `starhaven-release` 发布技能、智能体入口约定和开发者发布规范。维护者将通过检查的同一提交打为 `vVERSION` 标签后，自动完成 Mac 两种架构、Windows x64 安装版及便携版、公开源码包的构建与校验；只有全部成功才公开 Release。五个文件均附 SHA-256 校验文件，已发布版本不被不同内容覆盖。详见 [发布规范](https://github.com/2017Rocke/starhaven-town/blob/v1.13.0/docs/RELEASING.md)。

## 安装与验证范围

本地 Python 全套 203 项检查完成，197 项通过、6 项因平台或外部环境条件跳过，包含 28 项发布校验与失败恢复检查；Mac 安装器 4 项集成检查通过。房屋、星探行程、村心铺面、道路导航及双署工作区的前端检查通过，覆盖房屋同行对齐、工具避让门路、满载小车边界和绕开雕像的运输路线。隔离预览已检查最新村心布局的白天与夜景。

Mac ARM64 安装包已重新构建并更新本地应用，核对 39 个安装文件与当前源码一致，桌面入口正常。升级前后的居民、聊天、任务、安全档案及模型设置均保留，并保存本地备份。

公开安装包由该标签对应的三平台发布工作流生成，具体运行结果可在 Release 中追溯。Windows 构建与原生安装检查在 Windows Server 2022 执行；Windows 10.0.17763.379 仍需旧系统实机验收。Mac 安装包使用 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。
