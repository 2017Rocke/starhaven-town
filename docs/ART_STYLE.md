# 建筑美术规范

## 同一坐标与比例

- `StarhavenHouseArt.house(agent)` 和 `yard(agent)` 返回使用 320×280 地块坐标的 SVG 分组。调用方不再增加旧的 `translate(40 18)` 偏移。
- `layout(agent)` 提供 `hit` 矩形，以及 `label`、`resident`、`doorstep` 三个 `{x,y}` 锚点。房屋标签、交互和立绘应读取这些信息。
- 主门沿地块中心线布置。住宅正门到院外的中央通道留给居民；职业设施布置在两侧。地标建筑的下缘需避开村心主街。
- 细节使用整数像素，主体尽量使用 4 像素结构、2 像素修饰。边缘采用阶梯轮廓，避免曲线与模糊描边；地图缩放保持横纵比例一致。

## 材质与识别

屋顶、墙面、木料和石料分别保留基础、亮面、暗面层级，光源统一来自左上。用瓦缝、木板接缝、窗框和地基表达材质，减少无意义的密集纹理。门窗尺寸应与居民立绘协调。

职业特色至少有一个易辨认的大轮廓或道具组合：观测顶、旗塔、鸡舍、舞台、制图台、书架、晾鱼架等。主题装饰不能挡住门口或遮盖相邻地块。

夜景沿用统一的地图滤镜，窗灯与门灯在独立叠层中表现；不要为单栋建筑另做一套不一致的夜间颜色。日间建筑与夜间窗灯使用两个同坐标的根 SVG，滤镜作用于日间 SVG，避免 macOS WebKit 对内部 SVG 分组滤镜的兼容差异。窗前摆件不能与发光玻璃重叠，否则会被上层窗灯覆盖。昼夜两种皮肤均需检查。

## 渲染与验证

操作真实 SVG 节点时使用 `localName`、`getAttribute()` 和 `setAttribute()`。不要依赖测试替身的 `name` 或 `attrs` 字段。需要收窄细节时，应对左右边缘分别取整，保持相接边缘一致；不要在最终图层上做不等比拉伸。

几何检查覆盖所有房屋类别、像素坐标和尺寸、门口通道与布局锚点。自动检查不能替代真实浏览器观察：至少检查一栋普通住宅、指挥所、观察站，以及日间和夜间。桌面发布前还需在原生窗口核对夜景，不能仅凭 Chromium 预览判断 Mac 绘制效果。修改村心地标时，还需核对材料架点击、星探行程和建筑之间的道路。

## 街道与巡逻

- 外围路面、入口和巡逻必须读取 `map.road_network`，不能各自猜测街道范围。图中坐标采用世界坐标，矩形边界为左、上、右、下，世界宽度不能当成右边界。
- 北侧街道、其余横街与环路统一为 64px 双向马路，使用相同灰色底面、稀疏颗粒和车道线，避免密集错缝砖纹产生砌砖墙观感。横街两侧各保留 18px 路肩；村心两侧的外街端帽止于核心区边界，由同轴的村心马路接续。
- 最北排地块中心 y=90，地块底边 y=230；北街中心 y=280、路面 y=248..312，村心从 y=330 开始。森林整体北移 60px，世界顶部为 -580；美术与导航读取实际布局，不能只扩大路面而覆盖地块。
- 主街北侧 18px 路肩内安排 14px 步道，与路面边缘连续衔接，住宅入口铺面宽 32px；路缘在路口、入户和森林步道处留口，车道标线避开这些接入点。
- 路灯、低矮绿植和长椅只放在安全空隙，不占道路、步道、地块、材料架或森林入口。采用暖灰石色、木色与低饱和植被，细节尽量遵循 2px 网格。
- 警车横向 48×28、纵向 28×48，以车身中心定位；检查完整车身在道路范围内，转弯时不能仅检查中心点。动画表达真实任务的行动状态，不代表某户已检查通过。

## 村心马路与环岛

`town.svg` 的 `village-roads` 绘制村心马路，使用外围街道同样的灰色底面、稀疏颗粒、浅色标线与14px北侧步道。主街局部中心y390、路面y358..422全程笔直；北向道路中心x460、路面x428..492全程笔直。环岛移到两条轴线交点[460,390]，不得弯折主路来迁就环岛；三个外围入口及木桥完整同轴。建筑入口保持24px短径与门轴对齐，不从房屋图层重复画路。

环岛局部中心 `[460,390]`，内椭圆半径52×36、外椭圆116×100，轮廓使用4px阶梯。64px为名义环带规格，斜向轮廓允许像素量化误差。实际路面path采用evenodd挖空中央岛，不能把岛内算成车辆铺面；岛内放草地与雕像石台。雕像随环岛整体平移，世界视觉边界为 `[1380,646,1460,728]`；底座必须在岛内，上部形象属于前景投影。孔洞填色需与后方真实背景一致。

`village-bridge` 独立绘制原木色桥板与桥栏，局部净通道 `[780,358,894,422]`；栏杆与立柱在净通道之外。`village-garden` 的农田装饰整体南移16px，为环岛留出空间。不能用道路色盖住河流上的木桥。`app.plotOrigin` 从村心两侧最北住宅排推导两座地标的绘制行，当前world y390，与东日、钓鱼佬一致。房屋、灯光、按钮、居民和定位共用此位置；保存的角色资料和房屋坐标不改。领航地基/门阶底边y578，对应architecture；观察站y586，对应angling。24px门径分别从局部y248／256接到358。

材料架地图位置改为world `[1530,780]`，卸货点 `[1590,930]`。`StarhavenScoutJourney.YARD_ROUTE`仅用于院内短径；其后行走共用既有环岛与北路，不叠画石板。验证实际架体、人物脚点和雕像分图元，而非仅判断外接矩形。警车仍沿外围路图巡逻；本轮未将环岛加入车辆导航，不能把外围导航测试作为环岛行车证据。

两座地标的 `house-art.yard` 仅返回 `equipment` 分组，不另画地坪或门路。领航前庭左侧计划板、右侧会议桌，观察站左侧望远镜、右侧研究桌；设备不作为真实成果或技能调用的证明。每件设备须避开房屋、门道、马路和星探扫掠通道。材料架内手推车使用独立紧凑像素图形，满载边界为local `[166,94,238,154]`，不可用非整数缩放压扁现有图形。
