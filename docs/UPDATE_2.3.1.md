# 星栖小镇 2.3.1 · 居民分步工作与研发技能

更新日期：2026-11-16。版本标签：`v2.3.1`。下载见 [GitHub Release](https://github.com/2017Rocke/starhaven-town/releases/tag/v2.3.1)。

本版把长任务从一次等待改成可核对、可暂停和继续的分步工作，并发布此前在本地完善的居民培养、研发台和 Messages 模型接入。

## 所有居民共用的分步工作

- 聊天旁新增独立入口；支持目标、图文资料、来源引用、事实与推断、澄清问题和进度记录。
- 导入 TXT/Markdown、DOCX、PDF 和 PNG/JPEG/WebP。Word 嵌入图和 PDF 页面图在本机提取，图片净化后才用于模型请求；上传完成不等于模型理解完成。
- 长资料按片段处理并归并复核；暂停、重启或失败后保留完成步骤，继续未完成部分。回答问题或修订资料后重新核对受影响内容。
- 接入经合成验证的流式 Chat Completions / Anthropic Messages 和图像输入。当前模型看图验证未通过时明确暂停图片步骤；流式和看图资格各自验证，不以协议名称推定能力。隐藏推理不会保存或展示。

## 研发台与吉吉技能

- 项目绑定产品、开发、测试与总览居民；保存需求版本、答疑、确认、测试方案、私有代码候选和修改反馈。
- 杨辉需求分析复用分步工作。需求附件仅向本项目产品、开发和测试共享，私有开发材料不自动变为项目资料。
- 源码访问和应用本地改动需要原生确认。代码提交、推送由用户负责；真实测试、提交核验、部署及独立验收执行器尚未接入，本版不宣称自动研发闭环。
- 开发居民可导入本机支持的研发技能，按次选择技能及参考文档加入聊天。记录来源和版本，排除环境凭据；指南不会执行脚本或提升权限。
- 研发额度独立记账，可经原生确认放宽研发次数与 Token 总额；保留暂停、服务与居民授权、源码权限及每次用量核验。聊天、训练和普通分步工作继续遵守原额度。

## 培养与模型

- 成长署支持全镇目标、个人方向、近期重点、预期效果和七天建议课表；岗位课程减少近期重复，主观样稿等待人工验收。
- 支持 Anthropic Messages 的 API Key / Bearer 鉴权、缓存用量及明确失败原因。本机文字预算验证保留 4096 输出档，并提供单独验证的 32768 输出扩展档，旧档案不会自动升级。
- 保留已有居民编号、住处、记忆、聊天与训练记录，包括本地产品与测试形象。新存档仍为十三位初始居民，已有存档不强行重建角色。

## 稳定性修复

- 模型请求完成后先释放连接名额，再通知调用方，避免连续步骤误报“先前的模型连接仍在结束”。
- 本机验证记录统一按微秒精度比较时间，避免 Windows 同一时钟刻度下误判刚验证的模型；到期和撤销规则保持有效。

## 安装与支持范围

- 提供 Apple Silicon、Intel Mac、Windows x64 安装包和 Windows 便携包；图片和 PDF 解析组件随桌面包内置，无需用户安装 Python。
- 重新运行新版安装器更新应用，个人存档独立保存。私有需求、分步会话、本机技能和模型验证记录不进入公开源码或共享状态包。
- macOS 13+，默认 ad-hoc 签名，未完成 Apple Developer ID 公证。Windows 10 1809 x64（17763）为兼容目标；GitHub `windows-2022` 构建与安装验收不等于 Windows 10 `17763.379` 实机完整验收。

使用方式见 [分步工作与技能](RESIDENT_INTERACTIONS.md)、[研发台](DEV_WORKBENCH.md)、[居民培养](CULTIVATION.md) 和 [模型服务](MODEL_PROVIDERS.md)。
