# 星栖小镇 1.10.0 · 同一座小镇的建筑

更新日期：2026-11-12

这一版让居民住宅、指挥所和观察站使用同一套像素建筑语言。每栋建筑都能从轮廓、材质和职业设施上辨认，同时保持共同的门窗尺度、台阶和光影。

## 建筑与职业

| 建筑 | 视觉重点 |
| --- | --- |
| 指挥所 | 旗塔、团队公告与议事设施 |
| 观察站 | 阶梯式观测顶、望远镜与资料设施 |
| 节拍工坊 | 工具、加工设施、舞台、音箱与吉他 |
| 蓝图研舍 | 制图设施、建筑模型和研究展示 |
| 暖羽鸡舍 | 育雏空间、饲料、饮水与小鸡围栏 |
| 远足小屋 | 登山包、靴子、指路牌和石堆 |
| 垂钓小屋 | 茅草屋顶、鱼招牌、晾鱼架、池塘与木船 |
| 其他住宅 | 音乐、研学、行情与普通生活各有独立细节 |

职业与兴趣仍由现有角色资料决定。已有居民重新打开即可获得新版外观；更换头像不会自动改变职业住宅。

## 一致的比例与交互

建筑和院落统一采用 320×280 的地块坐标。主门、台阶、人物站位、点击区域和门牌使用共同的布局信息，避免独立调整房屋高度后出现人物离门、标签压屋顶等问题。住宅前的通道保持畅通，小径与大路衔接。

指挥所和观察站由同一个房屋绘制器生成，旧背景中的建筑图形已移除，保留村心河流、喷泉与道路。观察站材料架、星探出发点与森林行程继续使用已有位置，真实采集和交付逻辑保持原样。

日间保留柔和木石配色，星夜皮肤增加清晰的窗灯和门灯。沿用系统减少动态效果偏好。

## 升级与维护

安装新版桌面应用即可使用。居民身份、个性、记忆、聊天、模型连接设置与地块编号不因美术升级改变。安装器保留个人数据；升级前仍建议备份存档。

Mac 和 Windows 共用这套网页资源，本次不新增运行时依赖。Windows 10.0.17763.379 的完整实机验收与公开安装包状态，以对应正式 Release 为准。本地源码或预览版更新不等于 GitHub 安装包已发布。

后续新增建筑、皮肤请遵循 [建筑美术规范](ART_STYLE.md)。
