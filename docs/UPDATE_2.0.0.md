# 星栖小镇 2.0.0 · 成长署与受控协作

更新日期：2026-11-14。版本标签：`v2.0.0`。下载与构建结果见 [GitHub Release](https://github.com/2017Rocke/starhaven-town/releases/tag/v2.0.0)。

## 成长署成为小镇 HR

你只需确定培养方向、参与居民、模型和预算，成长署就会按岗位与近期任务记录制定每日基础练习。居民生成可复用方法、清单和示例，成果自动保存；不用再为每位居民逐一编写训练任务。

新安装增加成长官，共十一位初始居民，小镇最大容量三十三位。已有存档保留，满镇也能使用成长署工作区。自动训练默认关闭，需在桌面原生窗口确认授权后开启，且只在应用运行期间执行。

## 项目分工与成果验收

- 向领航提供整体项目目标与验收要求，程序按岗位匹配最多三位已授权居民，建立文本交付任务。
- 成果保存为不可变版本，支持人工资料导入、修订、交付、归档和来源追溯。副本与修订保留原始作者和资料限制。
- 基础训练可比较无本次参考的基线与使用练习参考后的独立案例结果，保存原始回答、规则、模型与调用证据。主观样稿和真实项目成果由所有者人工验收。
- 界面分别展示产出、验收、独立检查及有限任务中的对比改善；不会把生成文本当作模型权重升级或通用能力认证。
- 产出约定次日生效，支持工作日、分类、份数、单份长度与验收要求，并展示计入依据、排除原因和每日快照。

## 网络、资料与预算

稽查署统一检查居民调用授权、API 端点、模型和资料外发条件。允许访问某个端点不等于允许把全部资料发给它；每份引用资料都需要读取与外发许可，其来源限制会传递到副本和后续对话。

聊天与训练共享每位居民的每日、累计和单次预算。发送前预留额度，收到可靠用量回执后结算；发送后取消或用量未知时保守记账。修改策略、跨日和重启不会清除已发生的费用。页面可查看在途预留、剩余额度和调用记录，也可立即暂停全部培养或指定居民。

失败、中断和过期日计划不会自动反复执行；重试需要明确操作，逐项绑定当前授权。训练证据和既有账务保留。

## 参考技能与原生确认

技能是经审查和确认的参考文字，不执行命令，也不增加工具、联网或审批权限。每位居民最多启用五个版本；每次引用含依赖最多两个文本、总计 8 KiB，检查有效期三十天。停用依赖会连带停用相关技能。

培养设置、资料权限、人工验收、产出约定和技能启用均通过原生确认窗口处理。网页只能发起意图，确认绑定实际内容和权限快照，过期、变化或重复使用会被拒绝。

## 支持范围与升级

- 严格预算和自动训练当前仅适配 `https://api.openai.com/v1` 的 `gpt-4o-mini`、`gpt-4o-mini-2024-07-18`、`gpt-4o`、`gpt-4o-2024-08-06` 和 `gpt-4o-2024-11-20`。实际在线可用性取决于用户账户；本次未使用真实付费模型进行在线验收。
- 其他兼容 API 和本机模型保留兼容聊天；Codex 外部调用标记未计量，不能用于严格模式、受控资料引用或自动训练。
- 当前任务产出为文本；岗位分工采用内置规则，独立案例覆盖有限的边界与资料条件判断，不提供通用工具执行或完整职业能力认证。
- 首次升级 V2 数据结构前自动备份旧 SQLite 数据库。更新前仍建议退出应用并复制完整数据目录，保留附件和此后产生的记录。
- 发布工作流按同一不可变提交执行 Checks，以及两种 macOS 架构和 Windows x64 构建、安装集成检查；结果可在仓库 Actions 中追溯。
- Windows Server 2022 的构建与检查不等于 Windows 10 `17763.379` 实机验收。Mac 产物使用 ad-hoc 签名，未完成 Apple Developer ID 签名与公证。

完整操作步骤、资料权限、默认预算和迁移说明见 [V2.0 需求与实现说明](https://github.com/2017Rocke/starhaven-town/blob/v2.0.0/docs/GROWTH_V2.md)。
