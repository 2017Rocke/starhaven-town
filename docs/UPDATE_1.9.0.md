# 星栖小镇 1.9.0 · 宽敞院落与垂钓大屋

更新日期：2026-11-12

这一版把小屋之间的距离拉开，也给每栋房子更宽的院子。房屋本身没有缩放，改动集中在地块尺寸与道路布局上。

## 地块加高，院子变大

地块从 320×240 加到 **320×280**，行距从 280 拉到 **340**。院子净高从 52 像素变成 **92 像素**，行与行之间留出 60 像素草地。

世界高度相应扩到 2200，28 块地重排成五行（150 / 490 / 830 / 1170 / 1510）。地块内的房屋美术**整体不缩放**：多出来的 40 像素放在房子下方，作为院前的前景带，可以摆池塘前景、小路和低矮草木。

居民立绘原来贴着地块底边定位，地块变高后会向下坠、离开门口台阶。现在改成按顶部定位，立绘始终贴着自己家的门，院子变高不会把人和房子分开。

## 道路自动跟随行距

原来四条大路写死了 y 坐标，行距一改就会穿房。现在大路按**每一行之间的走廊**自动生成，门口小径按地块高度算。以后无论怎么调行距，道路都不会压到房子。

## 钓鱼佬的垂钓小屋

茅草顶从 16 行加到 **20 行**（64 → 80 像素），坡度更缓、屋檐更长，更像一栋真正的垂钓大屋。墙体、四扇窗、门廊雨棚、鱼字招牌、鱼饵桶和钓具箱一并下移，院内晾鱼架与池塘也跟着让位。

顺手修掉一个旧问题：门口的三级石阶原本写死在 y168/172/176，任何房子改高都会让台阶卡在原地。现在改为相对门口定位。

## 森林与星探不受影响

北侧两块地保持原来的 x 坐标（1197 / 1563），中间 46 像素的缺口就是北部森林的林道。星探从观察站出发、穿过村心、沿林道进入森林的整条路线已逐段核对，没有任何一段穿过房子。

观察站在村心老地图里，用归一化坐标定位，本次地块改动完全不涉及它。

## 升级说明

升级直接覆盖安装即可，聊天记录、居民资料、密钥和地块分配都会保留。地块位置由存档里的地块编号重新计算，所以升级后居民的房子会在地图上换位置，这是预期行为；村民身份、记忆和对话记录不受影响。

Mac 与 Windows 使用同一份网页资源。Windows 仍以 10.0.17763.379（Windows 10 1809）为兼容目标，依赖 .NET Framework 4.7.2 与 Edge WebView2。
