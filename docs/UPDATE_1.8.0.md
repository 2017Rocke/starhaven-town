# 星栖小镇 1.8.0 · 森林采集与热闹邻里

更新日期：2026-11-11

星探现在可以沿道路走向北部森林，寻找项目、带回真实材料并在观察站卸货。后台工作与居民行走分别进行：工作无需等待动画，动画也不会凭空产生项目成果。新安装的小镇同时拥有六位初始伙伴。

## 北部森林公园

地图向北扩展 520 像素，新增大小不同的像素树、林间采集点和连通小镇的步道。道路与住宅间隙衔接，现有村心、住宅地块和居民存档坐标保留。原有拖动、缩放、夜间皮肤和回到村心继续可用。

## 星探的一次出行

1. 点击「让星探出发」：后台立即搜索 GitHub，星探同时从观察站出发。
2. 沿道路到达森林：单程正常约 12 秒；林中活动随真实工作阶段显示指南针、手推车等道具。
3. 工作完成：有成功保存的项目才装载原木。即使任务很快完成，也会到达采集点短暂停留后再返程。
4. 运回材料：部分成功只运回取得的材料，失败原因继续保留；没有成果则空车返回，途中失败可就近掉头。
5. 卸货上架：到达院子后短暂卸货，再恢复可出发状态。

观察站分别显示工作进度、行动状态与材料数量。可定位星探，按需开启地图跟随；用户主动拖动地图时停止跟随。系统开启减少动态效果时，保持状态和定位可读，减少持续移动效果。

## 已保存、运输中与已上架

项目源码下载并校验后立即落盘保存，不会等星探走回家才写入文件。运送中的材料也可以查看；材料架只增加已经送达的可用材料。

行程依据持久化的任务记录与时间恢复，不依赖网页点击确认。切换视图、刷新或重新打开不会重复发放原木；重开时继续或补完交付。旧版已保存的材料直接视为已上架，不会重新播放旧任务。

星探尚在返程或卸货时不能重复出发；每日安排同样等待上一趟结束。采集仍受网络和 GitHub 匿名限流影响，遇到错误会显示真实原因。材料架画面最多展示六捆，文字数量显示实际库存。

## 六位初始伙伴

全新小镇包括领航、星探、吉吉、东日、科德和爬山佬，保留各自职业、性格、兴趣、外观与职业住宅。已有存档升级不覆盖居民，也不重复添加伙伴。

公开配置只包含整理后的角色档案，没有作者的聊天、私人记忆、模型配置或密钥。详见 [初始居民与个人存档](RESIDENTS.md)。

## 平台与升级

Mac 和 Windows 使用统一的 1.8.0 源码与资源，Windows 保留 1809 启动兼容和目录回退修复。Windows 最低目标为 10 1809 x64；本版本在较新 Windows 上的构建测试不能替代 `10.0.17763.379` 的完整验收。

Windows 仍依赖 WebView2，支持在程序旁放置固定版运行时，但标准安装包不默认包含该浏览器运行时。1809 默认使用会关闭浏览器进程沙箱的兼容模式，详见 [Windows 说明](WINDOWS.md)。

覆盖安装新版程序可保留个人数据。备份前完全退出小镇，通过「打开数据文件夹」确认实际目录，尤其注意 Windows 的回退数据目录。公开安装包与验证状态以本版本 GitHub Release 为准。

本版本包含 [1.7.0 观察站与像素住宅更新](UPDATE_1.7.0.md)。森林表现对应真实采集状态，尚不包含砍树后树桩与再生、其他居民自动加工、居民交接或自动深度研究。
