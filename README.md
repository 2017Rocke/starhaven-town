# 星栖小镇 · Starhaven Town

一个可以与智能体居民聊天、记录成长、观察团队工作的像素小镇。每位居民都有自己的名字、性格、简介、明确记忆和独立聊天记录。当前版本：**1.1.0**。

当前提供领航与星探两位居民、自定义居民、真实模型对话、任务板、成长册，以及「暖绿原野」「星夜营地」两套皮肤。应用和个人数据分开保存，方便后续更新功能与外观。

[下载 macOS 安装包](https://github.com/2017Rocke/starhaven-town/releases/latest) · [查看源码](https://github.com/2017Rocke/starhaven-town) · [如何上传与发布新版](docs/GITHUB_USAGE.md)

## 下载与使用

| 方式 | 适合谁 | 需要准备 |
| --- | --- | --- |
| macOS `.dmg` 安装包 | 希望安装后双击图标使用 | macOS 13 或更新版本；无需安装 Python、Node.js 或 Codex |
| 源码 ZIP / Git 仓库 | 开发者、Linux 用户、希望修改玩法的人 | macOS / Linux，Python 3.9 或更新版本；无需安装 pip 依赖 |

安装包应从本仓库 **Releases** 获取。GitHub 的 **Code → Download ZIP** 下载的是源码，不是可直接安装的桌面应用。当前本机验证目标为 Apple Silicon（arm64）；Intel（x86_64）构建与验证由后续对应环境完成，不能把一个架构的验证结果当作另一个架构的结果。

当前构建是本地 ad-hoc 签名预览版，尚未完成 Developer ID 签名和 Apple 公证。跨电脑下载可能被 macOS 阻止；面向公众的正常安装发布需要维护者完成签名与公证。这里不提供关闭 Gatekeeper 或删除系统安全标记的绕过步骤。

安装包内置了可重定位的 Python 运行时。**应用可以独立启动，AI 服务仍需由使用者配置**：可以连接自己的模型 API、本机兼容模型服务，或选择已经安装配置好的 Codex。

## macOS 安装、打开与更新

1. 打开适合自己架构的 DMG，双击「安装星栖小镇」。
2. 点击「安装并打开」。应用安装到 `~/Applications/星栖小镇.app`，桌面创建指向应用的图标。
3. 以后双击桌面图标即可打开。点击窗口红叉会隐藏窗口；使用菜单「退出星栖小镇」或 `⌘Q` 完整退出。
4. 更新时运行新版安装器。安装器等待应用退出、备份旧应用，再安装新版；个人资料和聊天记录保留。

当前没有在线自动更新服务。桌面图标是应用的符号链接，删除这个图标不会删除应用或个人数据。

## 连接 AI

打开页面右上角「小镇设置」，或 macOS 菜单「设置…」。

- **自选模型 API**：填写服务商提供的 API 基础地址、模型名称和自己的密钥。接口需兼容 OpenAI `chat/completions`，通常地址以 `/v1` 结尾。保存后发送一条消息检查实际连接。
- **本机模型**：填写例如 `http://127.0.0.1:11434/v1`，并填写已安装模型的准确名称。本机服务允许没有密钥；需要先自行启动对应模型服务。
- **Codex**：使用本机已有 Codex 配置。应用不包含 Codex，也不提供共享账户或额度。

远程地址必须使用 HTTPS，HTTP 仅允许 `localhost` 或 `127.0.0.1`。macOS 密钥保存在系统钥匙串，不写入项目文件、不回填到页面。Linux 源码方式使用 `STARHAVEN_API_KEY` 环境变量，不在文件中保存密钥。模型服务的费用和使用额度由使用者自己的账户承担。

发送消息会将该角色的资料、明确记忆、近期聊天及允许读取的工作摘要发送给所选服务。没有模型连接时，仍可查看小镇、编辑居民资料、切换皮肤和阅读已有记录。

## 源码运行

在项目目录运行：

```sh
python3 server.py --port 8877
```

然后打开 `http://127.0.0.1:8877`。macOS 也可以双击仓库中的「启动星栖小镇.command」。源码服务默认将数据保存在项目的 `data/`，使用 `--data-dir` 可以指定其他位置。停止终端服务后，网页将无法继续对话。

```sh
python3 -m unittest discover -s tests -v
```

测试使用临时数据与本机模拟服务，不需要模型密钥，不调用真实收费模型；部分测试需要允许绑定本机端口。

## 个人数据与团队连接

桌面版数据位于 `~/Library/Application Support/StarhavenTown/`。可通过菜单「打开数据文件夹」查看。居民、明确记忆、聊天历史与偏好存储在 SQLite 中，应用更新不会替换这个目录。备份时先退出小镇，再复制整个数据目录；不要只复制正在写入的数据库主文件。

通过 macOS 菜单「连接团队目录…」可选择包含 `config.json` 与 `state.json` 的协调官目录。小镇只读取团队进度与成果，不自动改写台账。首次下载不附带作者的聊天、模型密钥、个人路径或研究报告。

新增小镇居民是新增一个对话角色。当前没有自动派单、每周督办、自动能力训练或远程多用户服务；成长册中的真实成果需要有台账证据。对话不会自动同步到原 Codex 任务。
